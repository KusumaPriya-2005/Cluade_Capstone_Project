### PR title and description

**Title:** feat: add task manager package (taskmgr) for KAN-1

**Summary**

Adds `taskmgr`, a new standard-library-only package (Python 3.11+) that lets a user add, view, complete or reopen, edit, delete and filter tasks, and keeps them between sessions in a JSON file. It has a service layer with no I/O, a `TaskRepository` Protocol with in-memory and JSON-file implementations, and a thin `argparse` CLI. It follows the conventions of the existing `pwreset` library. No existing source file was changed.

**Linked requirements**

- Jira KAN-1 (US-01 to US-07), source `Inputs/test_user_story.md`.
- AC-1 to AC-17 are all met, each with an automated test (see `07-verification.md`).
  - AC-1 to AC-3 (add), AC-4 and AC-5 (view), AC-6 and AC-7 (complete and reopen), AC-8 and AC-9 (edit), AC-10 (delete), AC-11 and AC-12 (filter), AC-13 to AC-15 (persistence, missing and corrupt file), AC-16 (unknown id), AC-17 (standard library only, existing pytest settings).

- Tests: `tests/taskmgr_helpers.py` plus seven `tests/test_taskmgr_*.py` files (176 tests).

**Risks and known limitations**

- The distribution is still named `pwreset` (description "Password reset service layer") and now ships two packages, `pwreset` and `taskmgr`. The name and description were deliberately not changed.
- There is no `[project.scripts]` entry. Run the CLI as `python -m taskmgr` with `src` on `PYTHONPATH`, or after `pip install -e .`.
- Concurrent processes can lose an update (no file locking). Documented only, with no test.
- `README.md` does not describe `taskmgr` yet. A follow-up is advisable.
- Code-review advisories A1 to A7 are left open and none is blocking (for example, A1: assert that a temp file was left in the cleanup test; A2: cross-step ordering cases in the corrupt-file table; A7: weak `--` assertion in `test_help_returns_0`).
- A corrupt storage file aborts with exit code 3 and is never overwritten. Titles containing control characters are rejected, and titles or ids starting with `-` need `--` on the command line.
